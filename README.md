# Vai Comigo

Mobilidade assistida e acessível para pessoas idosas, com apoio de familiares.

## Produto

O Vai Comigo reduz a carga de pedir uma corrida sem retirar da pessoa passageira a decisão final. A primeira versão deve simplificar destinos conhecidos, explicar claramente o próximo passo e encaminhar para o aplicativo oficial de mobilidade.
