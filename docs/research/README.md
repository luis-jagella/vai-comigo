# Pesquisa com usuários

Este diretório contém o kit de descoberta da issue #1. Ele orienta entrevistas com pessoas idosas e familiares sem colocar dados pessoais no repositório público.

## Objetivo desta rodada

Entender como as pessoas solicitam transporte hoje, onde sentem insegurança e qual nível de ajuda preserva sua autonomia.

## Materiais

1. [Plano de pesquisa](research-plan.md)
2. [Convite para participantes](participant-invitation.md)
3. [Roteiro de consentimento](consent-script.md)
4. [Roteiro de entrevista](interview-guide.md)
5. [Template de notas](session-notes-template.md)
6. [Template de síntese](synthesis-template.md)
7. [Tratamento dos dados de pesquisa](data-handling.md)

## Regra de ouro

Somente resultados agregados e anonimizados podem entrar neste repositório. Gravações, nomes, telefones, endereços, coordenadas, placas, contas e relatos que identifiquem participantes não devem ser versionados.

## Resultado esperado

Ao finalizar a rodada, criar `docs/research/findings-round-01.md` a partir do template de síntese. O arquivo deve registrar evidências, limitações e decisões, sem apresentar participantes individualmente.
