## Metadados mínimos

- Código da sessão: `PXX` ou `FXX`
- Perfil: pessoa passageira / familiar
- Familiaridade digital: baixa / média / alta, conforme autoavaliação
- Usa recurso de acessibilidade: não informado / sim, descrito apenas se relevante
- Consentimento confirmado: sim / não
- Facilitador e observador: códigos internos

Não registrar nome, data de nascimento, contato, endereço, coordenadas, diagnóstico, placa, motorista ou dados de conta.
